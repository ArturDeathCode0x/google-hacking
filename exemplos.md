# 🔬 Google Hacking — Exemplos Práticos

Coleção de operadores de busca do Google para pesquisas avançadas e autorizadas.

---

## 📚 Operadores

### 1. Pesquisa por domínio

**Operador:** `site:`

```
site:example.com
```

**Objetivo:** localizar páginas indexadas de um domínio específico.

### 2. Pesquisa por arquivos

**Operador:** `filetype:`

```
site:example.com filetype:pdf
```

**Objetivo:** encontrar documentos PDF públicos.

### 3. Pesquisa em títulos

**Operador:** `intitle:`

```
site:example.com intitle:documentação
```

**Objetivo:** localizar páginas que possuem determinado termo no título.

### 4. Pesquisa em URLs

**Operador:** `inurl:`

```
site:example.com inurl:blog
```

**Objetivo:** encontrar páginas com determinado termo no endereço.

### 5. Pesquisa no conteúdo

**Operador:** `intext:`

```
site:example.com intext:"política de privacidade"
```

**Objetivo:** localizar páginas que contenham uma expressão específica.

---

## 🛡️ Observações

- Os exemplos utilizam um domínio fictício.
- Resultados dependem da indexação do Google.
- Utilize as técnicas somente em pesquisas autorizadas.
- Não acesse ou divulgue informações privadas.
